Material-Professor

Esta pasta guarda o material original fornecido pelo curso Python for Machine Learning & Data Science Masterclass, do professor Jose Portilla (Pierian Data).

O QUE É ESTA PASTA

Tudo o que está aqui foi produzido pelo professor e pela Pierian Data. Nada desta pasta é de minha autoria. Ela existe somente para que eu acompanhe as aulas e consulte o material durante os estudos.

O QUE FICA AQUI

- Os notebooks das aulas, organizados pelas seções do curso, do Python Crash Course ao Model Deployment.
- A pasta DATA, com os conjuntos de dados usados nas aulas.
- O arquivo compactado original do material e o logotipo do curso.

POR QUE ESTA PASTA É SEPARADA

Eu separo o material do professor do meu trabalho para que ninguém confunda os dois. Quem visitar o repositório deve conseguir ver, sem esforço, o que veio do curso e o que eu produzi. O que eu produzo fica somente na pasta Minha-Jornada.

OS ARQUIVOS ORIGINAIS NÃO SÃO PUBLICADOS

Como o material pertence ao professor e à Pierian Data, eu não publico os arquivos originais neste repositório. Os arquivos ficam apenas no meu computador, e o único arquivo desta pasta que vai para o GitHub é este README. Quem quiser o material original pode obtê-lo pela plataforma onde o curso é oferecido.

COMO EU USO ESTE MATERIAL

- Acompanho cada aula com o notebook do professor aberto.
- Depois, refaço os exercícios na pasta Minha-Jornada, sem copiar o código do professor.
- Quando eu consulto uma solução do professor, eu registro isso no meu notebook.

ÉTICA ACADÊMICA

Manter esta separação é uma escolha consciente: eu quero que o meu repositório mostre o meu aprendizado de forma honesta. O crédito do conteúdo das aulas é do professor, e o crédito do que eu escrevo em Minha-Jornada é meu.

Voltar para o README principal do repositório para ver o propósito geral.
